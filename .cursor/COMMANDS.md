# ai-config Cursor Commands

在 Cursor 聊天输入 `/` 选择下列命令。

| 命令                 | 说明                                     |
| -------------------- | ---------------------------------------- |
| `/speckit.specify`   | 从自然语言创建 `specs/<feature>/spec.md` |
| `/speckit.plan`      | 基于 spec 写 `plan.md`                   |
| `/speckit.tasks`     | 拆解 `tasks.md`                          |
| `/speckit.implement` | 按 tasks 实现并验证                      |
| `/ai-config-verify`  | 跑 cargo test、GUI build、doctor         |
| `/ai-config-sync`    | 本地安装/同步冒烟与排障指引              |

Spec Kit 宪法：`.specify/memory/constitution.md`
